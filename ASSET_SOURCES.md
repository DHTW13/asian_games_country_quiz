# Asset sources

- Country boundary source: Natural Earth Vector country data. Natural Earth states its vector/raster map data are public domain.
- The country SVG files in `assets/countries/` are locally generated SVG exports of the bundled boundary geometries.
- Flag SVG files in `assets/flags/` are local vector assets generated from the **worldflags** LaTeX/TikZ package (Wilhelm Haager). CTAN lists worldflags under the LaTeX Project Public License 1.3 or above.
- Hong Kong and Macau flag SVGs are small local vector reconstructions included for this project.

The game does not include official Asian Games logos or mascots.
